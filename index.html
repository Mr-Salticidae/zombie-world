▍手机 / 平板怎么玩

射击：手指按住屏幕右半边就会开火；按住不动会自动瞄最近的敌人，拖动则朝拖的方向瞄准（仍带小幅吸附）。
移动：手指按住屏幕左半边拖动，就地生成摇杆。
换武器：点右下角 换枪 键循环切换（自动跳过没子弹的枪）；也可以直接点最下面那排武器格指定一把—— 左半边是走位区，压在武器格上照样能拖着走，只点一下不拖才算换枪。
无双：点右下角红色圆键。暂停：点左上角 ❚❚。
波间商店：一波打完自动弹出，点货架买东西，买完点「开打」进下一波。
竖屏也能玩：竖屏会自动换成竖版视野，横过来则是宽视野，不用非得转屏。

▍电脑操作

键盘经典模式：WASD 或方向键移动； 开着自动瞄准时会自己转向锁定的敌人，所以可以边往后撤边打身后的僵尸
鼠标射击模式：左键点击/按住朝指针方向攻击；右键点击移动到该点、按住持续跟随；也可用 WASD 移动
射击：左键 / 空格 / J（可按住连射）
切换武器：鼠标滚轮 / Q E / 数字键 1－9 ｜ 暂停：P / Esc
自动瞄准（主菜单与暂停页可开关，默认开）：没在自己瞄的时候——键盘经典模式、 或手机按住右半边不拖——枪口自动跟住范围内最近的敌人，被锁的那只身上会有黄色括号。 自己在瞄的时候——鼠标、或拖动右摇杆——只在准星附近做小角度吸附，方向仍然听你的。 锁定半径跟着枪走：喷火器只锁贴脸的，火箭筒能锁到屏幕边；超出屏幕的一律不锁。 被石柱挡住的不锁（子弹反正也打不到），范围内全被挡住时枪口交还给你。 换目标时枪口是扫过去的，不会瞬间甩到背后
瞄油桶：按住 Shift 枪口就甩到最近的油桶上（括号变橙色），松开回到锁敌； 范围内没有油桶时等于临时把瞄准交还给你。鼠标 / 拖摇杆时不用按——准星压在油桶上 就优先于旁边的僵尸，不会被吸走
无双大招：按 R 或点击右下角图标发动，化身近战大师，双刀乱舞并吸血，持续 15 秒； 开局自带一次，之后每击杀 50 个敌人重新充能
主菜单可选 5 种战场地图（带实时预览）与 3 档难度（轻松 / 标准 / 硬核）
排行榜：主菜单进，分 得分榜 与 坚守波数榜，各有总榜与本周榜。 阵亡结算页可把成绩传上榜（只统计标准难度，轻松 / 硬核 的局不计入）

▍金币与波间商店

击杀会掉金币，走近就自动飞过来（放久了吸得更远，不用特意去捡）。 普通僵尸 2、红恶魔 8、BOSS 24~88；金币不受连击倍数影响。
一波打完自动弹出波间补给：买弹药包（每把已解锁的枪一格，越靠后解锁的越贵）、 医疗包（+35 生命 / 40）、无双充能（+1 次 / 120，最多存 2 次）。 买完点「开打」进下一波——单人时它会一直等你。
商店只卖消耗品，枪买不到：枪一律靠连击倍数解锁。 金币只在这一局有效，重开就归零，不影响排行榜。

▍游戏规则

抵御从四周涌来的方块头僵尸与会喷火球的红恶魔。每波一只 BOSS，前五波五级递进： 壮汉巨尸（召唤）→ 掠行猎尸（连环冲锋+毒吐）→ 碎地暴尸（召唤/冲锋/震地）→ 灾祸巨像（再加全向弹幕）→ 僵尸博士（巨大体型·全技能·毒池·残血狂暴）。 第 6 波起 BOSS 在前四级之间轮转并逐波变强，每逢 5 的倍数波僵尸博士再次登场。 脚下红圈/绿圈是技能预警，快躲开！击破 BOSS 必掉补给，每波打完还会回复生命。 连续击杀提升连击倍数， 倍数达到 ×3 / ×5 / ×8 / ×11 / ×13 / ×15 / ×17 / ×20 依次解锁： 马格南、乌兹冲锋枪、霰弹枪、加特林、手雷、油桶、喷火器、火箭筒。 解锁不会把枪从手里换掉——手上这把还能打就接着打，自己挑时机换。 受到伤害连击减半。敌人偶尔掉落医疗箱与弹药箱。地上的油桶射击即可引爆（按住 Shift 直接瞄），还会连环殉爆！
